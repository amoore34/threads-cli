# Threads CLI

A keyboard-first terminal application for browsing Threads in a clean, distraction-free interface.

## Features

- Terminal user interface (Textual)
- Keyboard navigation
- Split-pane layout
- Thread preview
- Future AI summaries
- Bookmarks
- Search
